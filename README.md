# Lunara

Telegram-бот расписания МИИГАиК для одной учебной группы. Lunara показывает
занятия из локального кеша, следит за изменениями на сайте университета и умеет
отправлять расписание в отдельный топик группового чата.

Текущая конфигурация рассчитана на группу **2023-ФУТ-УпрК-1б**
(`groupId=1306`), но группу можно заменить через переменные окружения.

## Что умеет бот

- Показывать расписание на сегодня, завтра, текущую или следующую неделю.
- Сворачивать подробные карточки, чтобы длинное расписание не занимало весь чат.
- Находить ближайшую ещё не начавшуюся пару.
- Показывать расписание на произвольную дату.
- Отображать экзамены из отдельного раздела сайта МИИГАиК.
- Давать ссылку на аудиторию через официальную карту `map.miigaik.ru`.
- Замечать изменения времени, преподавателя, аудитории, типа и номера пары.
- Подтверждать изменение повторной проверкой через 10 минут.
- Хранить историю подтверждённых изменений.
- Работать в личных сообщениях и в одном выбранном Telegram-чате или топике.
- По желанию отправлять расписание на завтра и следующую неделю.
- Продолжать отвечать из PostgreSQL, когда сайт временно недоступен.

Бот не объявляет пару отменённой. Если занятие исчезло из источника, сообщение
формулируется как «убрано из расписания». Массовое исчезновение занятий попадает
в карантин и требует ручного подтверждения владельцем.

## Команды

| Команда | Результат |
|---|---|
| `/today` | Расписание на сегодня |
| `/tomorrow` | Расписание на завтра |
| `/week` | Текущая календарная неделя |
| `/nextweek` | Следующая календарная неделя |
| `/next` | Ближайшая ещё не начавшаяся пара |
| `/day ДД.ММ.ГГГГ` | Расписание на выбранную дату |
| `/changes` | Последнее изменение и более ранняя история |
| `/exams` | Экзамены группы |
| `/start`, `/help` | Название группы и справка |

Команды вида `/week@LunaraSchedulebot` также поддерживаются.

Пример карточки занятия:

```text
📅 Вторник, 29 сентября 2026
🔼 Верхняя неделя

⏰ 4 пара · 14:30–16:00 · лекция
📚 Инженерное обустройство территорий
👤 Снежинская Елена Юрьевна
📍 53 (Старый корпус) · Карта
```

Недельный обзор объединяет дни в одно компактное сообщение, когда позволяет
лимит Telegram. Полные названия дисциплин сохраняются; преподаватель, тип и
аудитория доступны в подробном расписании конкретного дня.

## Откуда берутся данные

Основной источник — [публичное расписание МИИГАиК](https://study.miigaik.ru/).
Бот получает серверный HTML без запуска браузера, проверяет выбранную группу,
даты, времена и структуру карточек, а затем сохраняет нормализованные данные в
PostgreSQL.

Команды Telegram не обращаются к сайту напрямую. Они читают последний
подтверждённый снимок из базы, поэтому отвечают быстро и продолжают работать при
кратковременном сбое источника.

Watcher по умолчанию проверяет текущую и следующую недели раз в сутки. Если
содержимое изменилось, тот же результат должен повториться не раньше чем через
10 минут. Только после этого новая версия становится действующей и отправляется
одно уведомление.

Защита от ложных уведомлений включает:

- проверку HTTP-ответа и HTML-структуры;
- отказ от частично разобранных недель;
- повторное подтверждение изменений;
- карантин при уменьшении числа занятий на 30% и более;
- безопасную смену версии парсера без массовой рассылки;
- последовательные запросы к источнику с ограничением частоты и повторами.

## Быстрый запуск через Docker Compose

Понадобятся Docker с Compose v2, Telegram-бот от `@BotFather` и ID целевого
чата. Домен, HTTPS и открытый входящий порт не требуются: используется Telegram
long polling.

```sh
git clone https://github.com/LeezyWannaFall/Lunara.git
cd Lunara
cp .env.example .env
chmod 600 .env
```

Заполните `.env`:

```env
GROUP_ID=1306
GROUP_NAME=2023-ФУТ-УпрК-1б

TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=-1001234567890
# Только если сообщения должны идти в определённый топик:
TELEGRAM_THREAD_ID=42

POSTGRES_USER=lunara
POSTGRES_DB=lunara
POSTGRES_PASSWORD=случайный_надёжный_пароль
```

Сгенерировать пароль PostgreSQL можно командой:

```sh
openssl rand -hex 24
```

Проверка конфигурации и запуск:

```sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 bot
```

Compose поднимает три сервиса:

- `postgres` — постоянное хранилище расписания и состояния;
- `migrate` — разовое применение миграций, нормальный итог `Exited (0)`;
- `bot` — Telegram polling, watcher и доставка сообщений.

PostgreSQL не публикует порт на хост. `bot` и `postgres` используют
`restart: unless-stopped` и запускаются снова после перезагрузки Docker/VPS.

Остановка без удаления данных:

```sh
docker compose down
```

Команда ниже удаляет контейнерную базу без возможности восстановления и для
обычного обновления не нужна:

```sh
docker compose down --volumes
```

## Telegram-чат и топики

В личных сообщениях бот доступен всегда. В группах он принимает команды только
из `TELEGRAM_CHAT_ID`. Если указан `TELEGRAM_THREAD_ID`, команды из других
топиков игнорируются, а ответы, изменения и рассылки отправляются в выбранный
топик.

Боту обычно не требуются права администратора: достаточно добавить его в чат и
разрешить отправку сообщений. При включённом privacy mode команды можно писать
как `/week@LunaraSchedulebot`.

## Добровольные рассылки

Обе рассылки по умолчанию выключены:

```env
REMINDER_TOMORROW_ENABLED=false
REMINDER_WEEKLY_ENABLED=false
```

Если их включить:

- расписание на завтра отправляется ежедневно в 19:00;
- расписание следующей недели отправляется в воскресенье в 19:00;
- используется `TIMEZONE`, по умолчанию `Europe/Moscow`;
- пропущенные во время остановки сообщения не досылаются;
- задания дедуплицируются по чату, виду рассылки и дате.

## Основные настройки

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `GROUP_ID` | Числовой ID группы на сайте | `1306` |
| `GROUP_NAME` | Название в сообщениях | `2023-ФУТ-УпрК-1б` |
| `TELEGRAM_BOT_TOKEN` | Токен Bot API | обязательно |
| `TELEGRAM_CHAT_ID` | Разрешённая группа и получатель уведомлений | пусто |
| `TELEGRAM_THREAD_ID` | Разрешённый топик | пусто |
| `TIMEZONE` | Часовой пояс команд и рассылок | `Europe/Moscow` |
| `BOOTSTRAP_WEEKS` | Число недель первоначальной загрузки | `2` |
| `WATCH_WEEKS` | Число недель регулярной проверки | `2` |
| `WATCH_INTERVAL` | Обычный интервал watcher | `24h` |
| `CONFIRMATION_DELAY` | Задержка подтверждения изменения | `10m` |
| `EXAM_INTERVAL` | Интервал обновления экзаменов | `24h` |
| `REMINDER_TOMORROW_ENABLED` | Вечерняя рассылка на завтра | `false` |
| `REMINDER_WEEKLY_ENABLED` | Воскресная рассылка недели | `false` |
| `LOG_LEVEL` | Уровень JSON-логов | `info` |

Полный образец находится в `.env.example`. При Docker-запуске Compose
автоматически загружает `.env`. При обычном `go run` файл `.env` автоматически
не читается — переменные нужно передать процессу через окружение.

## Обновление на VPS

```sh
cd /opt/lunara
git pull --ff-only
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 bot
```

Миграции применяются автоматически отдельным сервисом до запуска новой версии.
Данные PostgreSQL остаются в именованном Docker volume.

## Локальная разработка и тесты

Требуется Go 1.26 или новее:

```sh
go test -race ./...
go vet ./...
go build ./...
```

PostgreSQL integration tests запускаются без Docker во временном локальном
кластере:

```sh
bash scripts/test-integration.sh
```

Обычные тесты источника используют сохранённые HTML fixtures и локальный
`httptest`; они не обращаются к живому сайту.

## Структура проекта

Lunara остаётся одним Go-приложением с PostgreSQL:

- `cmd/bot` — основной процесс;
- `cmd/migrate` — миграции;
- `cmd/admin` — просмотр и принятие карантина;
- `cmd/schedule` — ручная проверка источника или кеша;
- `internal/source/miigaik` — HTTP-клиент и HTML-парсеры;
- `internal/schedule` — модели и календарь верхней/нижней недели;
- `internal/changes` — сравнение занятий;
- `internal/storage` — PostgreSQL;
- `internal/telegram` — Bot API, команды и форматирование;
- `internal/scheduler` — bootstrap, watcher, рассылки и доставка.

Подробное объяснение движения данных, моделей, транзакций и обработки ошибок —
в [ARCHITECTURE.md](ARCHITECTURE.md).

## Ограничения

- Проект обслуживает одну группу из конфигурации.
- Источник не предоставляет стабильный ID занятия, поэтому неоднозначные замены
  отображаются как удаление и добавление.
- Разрыв соединения после успешной отправки Telegram, но до фиксации message ID,
  теоретически может привести к повтору сообщения.
- Изменение HTML сайта может потребовать обновления парсера.
